Margen

Prefijo m-valor entre 0 y 5

Para modificar en una dirección específica usar:

mt para el margen hacia arriba
mb para el margen hacia abajo
ms para el margen hacia el inicio (normalmente izquierda)
me para el margen hacia el final (normalmente derecha)
mx para el margen hacia la izquierda y derecha
my para el margen hacia arriba y abajo

Padding (espacio vacío interior)

Prefijo p-valor entre 0 y 5

Para modificar en una dirección específica usar:

pt para el padding hacia arriba
pb para el padding hacia abajo
ps para el padding hacia el inicio (normalmente izquierda)
pe para el padding hacia el final (normalmente derecha)
px para el padding hacia la izquierda y derecha
py para el padding hacia arriba y abajo
